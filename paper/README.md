# Paper

`main.tex` and `references.bib` build the paper from the results in this repository. Every number comes from `results/` and `outputs/` in this repository and from ProcureGateBench v0.1.0 (doi:10.5281/zenodo.24223130). The post-hoc analysis is `scripts/policy_in_code.py`.

```bash
latexmk -pdf main.tex
```
