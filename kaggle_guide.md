# Kaggle dataset preparation guide

The current v0.1.0 dataset is synthetic and is suitable for publishing as a small reproducibility fixture, not as a representative sample of biodiversity records.

Suggested Kaggle dataset title: **EcoRecordTriageBench: Synthetic Biodiversity Occurrence Metadata QA Cases**

Before uploading:

1. Include `data/scenarios.jsonl` and `data/DATA_CARD.md`.
2. State prominently that every record is synthetic and coordinates are not real observations.
3. Keep the CC0-1.0 dataset licence separate from the MIT code licence.
4. Include the repository commit hash and dataset SHA-256 in the Kaggle description after the GitHub release exists.
5. Do not imply that the benchmark measures real-world biodiversity data quality or species identification accuracy.

No Kaggle upload has been performed by this project generator.
